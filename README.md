# MediaConverter

Настольное приложение для Windows для пакетной конвертации аудио- и видеофайлов, построенное на .NET 8 WinForms с FFmpeg в качестве бэкенда.

## Возможности

- **Очередь задач** — добавляйте неограниченное количество файлов и конвертируйте их последовательно одним запуском
- **Drag-and-drop** — перетащите файлы прямо в окно или на список задач
- **Форматы вывода** — MP4, MP3, WAV, AAC, FLAC
- **Выбор кодека** — H.264, H.265 или потоковое копирование для видео; AAC, MP3, FLAC или копирование для аудио
- **Пресеты** — готовые профили в одно нажатие: Web, High Quality, Remux, Audio MP3, Lossless FLAC
- **Прогресс в реальном времени** — процент выполнения на уровне каждого файла через FFmpeg `-progress pipe:1`
- **Отмена** — остановка текущего пакета без потери уже сконвертированных файлов
- **Итоговый диалог** — сводка по завершении: количество успешных/ошибочных, затраченное время и кнопка открытия папки
- **Двуязычный интерфейс** — переключение между русским и английским без перезапуска

## Архитектура

```
MediaConverter/
├── Program.cs               # Точка входа, ApplicationConfiguration
├── MainForm.cs              # Логика главного окна, управление очередью, оркестрация конвертации
├── MainForm.Designer.cs     # Авторазметка WinForms
├── ConverterService.cs      # Обёртка над процессом FFmpeg: ConvertAsync, зондирование длительности, детектирование видеопотока
└── SuccessForm.cs           # Диалог с итогами пакета
```

`ConverterService` не зависит от UI и взаимодействует с MainForm через `IProgress<ConversionProgress>`. Цикл конвертации выполняется на UI-потоке через `async/await`, сохраняя отзывчивость интерфейса.

## Требования

| Компонент | Версия |
|-----------|--------|
| Windows | 10 и выше (64-bit) |
| .NET Runtime | 8.0 |
| FFmpeg | 4.4+ (должен включать `ffprobe`) |

### Установка FFmpeg

**Через winget:**
```cmd
winget install Gyan.FFmpeg
```

**Через Scoop:**
```cmd
scoop install ffmpeg
```

**Через Chocolatey:**
```cmd
choco install ffmpeg
```

**Вручную:** скачайте сборку с [ffmpeg.org](https://ffmpeg.org/download.html) и добавьте папку `bin/` в переменную среды `PATH`.

Проверьте установку:
```cmd
ffmpeg -version
ffprobe -version
```

## Сборка и запуск

1. Откройте `MediaConverter.sln` в Visual Studio 2022 или новее.
2. Выберите конфигурацию **Debug** или **Release**.
3. Нажмите **F5** для сборки и запуска.

Либо через CLI:
```cmd
dotnet build MediaConverter.sln
dotnet run --project MediaConverter
```

## Использование

1. **Добавить файлы** — нажмите **Добавить файлы** или перетащите медиафайлы в окно.
2. **Выбрать профиль** — нажмите **Пресеты** и выберите готовый профиль *или* вручную настройте формат, видеокодек и аудиокодек.
3. **Задать папку вывода** — по умолчанию `Видео\Converted`; нажмите **Обзор** для смены.
4. **Запустить** — нажмите **Начать конвертацию**. Каждая строка в очереди обновляется в реальном времени.
5. **Отменить** — нажмите **Отмена** для остановки пакета; уже сконвертированные файлы сохраняются.
6. **Настройки** — включите *«Открыть папку вывода после конвертации»* для автоматического открытия папки по завершении.

## Поиск FFmpeg

Приложение ищет `ffmpeg.exe` и `ffprobe.exe` в следующем порядке:

1. Переменные среды `FFMPEG_PATH` / `FFPROBE_PATH`
2. Системный `PATH`
3. Стандартные пути установки: scoop shims, WinGet packages, Chocolatey, `C:\ffmpeg\bin\`
4. Директория приложения (`{exe}/ffmpeg/bin/`)
